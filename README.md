# Curso de Lógica de Programación en JavaScript

Minicurso práctico para aprender a **pensar como programador**, usando JavaScript como lenguaje de práctica. La lógica que aprendas aquí aplica igual para Python, Java, C# o cualquier otro lenguaje — solo cambia la sintaxis.

📺 **Mira el curso completo en video:** [youtu.be/3Ux3iYpHlac](https://youtu.be/3Ux3iYpHlac)

## 🎯 Enfoque

Cada archivo del curso sigue el mismo formato:
1. **Concepto breve** — explicado con analogías simples
2. **Ejercicios de "predice el resultado"** — piensa antes de correr el código
3. **Ejercicios de "encuentra el error"** — detecta bugs de lógica comunes
4. **Resumen "para llevar"** — lo esencial del módulo

No es solo memorizar sintaxis: es entrenar el razonamiento lógico que necesitas para programar en cualquier lenguaje.

## 🚀 Cómo usarlo

Cada archivo es independiente y ejecutable. Puedes correrlo:

- **En el navegador**: abre la consola (F12 → pestaña "Console") y pega el código
- **Con Node.js**: `node nombre_del_archivo.js` (nota: los `prompt()` del módulo 2 solo funcionan en navegador)

Recomendamos ir en orden (0 → 9), ya que cada módulo se apoya en el anterior. Sigue el video para la explicación completa de cada concepto.

## 🏆 Proyecto final

El módulo 9 (`proyecto_final.js`) integra todo lo aprendido en un mini sistema de validación de acceso a eventos, con un reto final para extenderlo usando arrays, bucles y funciones propias.
